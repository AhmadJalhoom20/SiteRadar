# SiteRadar

A local SEO/GEO audit workspace. Configure a public, authorized site, collect bounded HTML evidence, prioritize fixes, and export findings and a repair prompt. Primary audience: site owners and developers. Platform: web, Next.js / Node.js / Tailwind. English interface with target-language configuration; Arabic/RTL product localization is a later extension.

Sample mode explains the report without pretending the example is a live measurement. Live scans use a durable local job queue and truthful capability states. This local version is single-user and must remain bound to loopback until authentication and tenant isolation are implemented.
