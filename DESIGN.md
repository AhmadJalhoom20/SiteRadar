# SiteRadar — precise, calm, evidence-led

Operate mode. For owners and SEO teams deciding what to fix next. Essence: quiet search intelligence.

Light canvas, dark forest navigation, lime cursor accents, fine dividers, generous main-panel spacing. No decorative gradients, glass, or floating tiles. The signature is a concentric radar score inside an open report layout.

Typography: self-hosted Manrope and IBM Plex Mono (Fontsource), 14px base, 1.25 scale: 11/14/18/22/28/35. Dark green ink; secondary gray-green. Tabular numbers for measurements. 4px spacing unit; 8px/12px corners. Borders provide separation, subtle elevation only for overlays.

Tailwind v4 with CSS role tokens: canvas oklch(0.98 0.004 150), surface white, ink oklch(0.24 0.025 155), muted oklch(0.51 0.012 155), forest oklch(0.30 0.06 157), accent oklch(0.87 0.16 125), border oklch(0.91 0.008 150). Semantic amber/red/green reserved for findings.

Use real labels, Radix dialog focus management, visible focus, reduced motion, responsive navigation. Sample measurements always carry an explicit example label. Never imply an unmeasured rank or AI citation.
